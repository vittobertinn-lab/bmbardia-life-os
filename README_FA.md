# BARDIA LIFE OS V10

نسخه ۱۰ یک برنامه وب قابل نصب (PWA) برای مدیریت کارها، عادت‌ها، درس‌ها، تمرکز و برنامه‌ریزی هفتگی است.

## قابلیت‌های نسخه ۱۰
- برنامه‌ریز هفتگی با بازه‌های زمانی شروع و پایان
- جلوگیری از ثبت بازه‌های هم‌پوشان در یک روز
- ثبت انجام‌شدن هر بازه و محاسبه درصد تکمیل هفته
- حفظ امکانات نسخه ۹: مدیریت کارها، عادت‌ها، درس‌ها، تایمر تمرکز، گزارش‌ها و پشتیبان JSON
- ذخیره‌سازی محلی روی همان مرورگر/دستگاه

## اجرا
فایل ZIP را استخراج کن و `index.html` را برای پیش‌نمایش باز کن. برای نصب PWA باید پروژه روی یک میزبان HTTPS مثل GitHub Pages یا Vercel منتشر شود؛ سپس در Chrome اندروید گزینه Install app / Add to Home screen را بزن.

## نکته مهم درباره داده‌ها
اطلاعات روی همان دستگاه و مرورگر ذخیره می‌شود؛ حساب کاربری، همگام‌سازی ابری یا رمزگذاری اختصاصی وجود ندارد. از بخش تنظیمات مرتباً فایل JSON پشتیبان بگیر. برای انتقال اطلاعات، فایل پشتیبان را در دستگاه مقصد بازیابی کن.

## تغییرات V10
برنامه‌ریز هفتگی زمان‌محور اضافه شده است. برای جلوگیری از برنامه‌ریزی غیرواقعی، بازه‌های زمانی هم‌پوشان در یک روز رد می‌شوند.
